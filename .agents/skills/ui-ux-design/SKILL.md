# UI/UX design

## Responsibilities

Shape clear, accessible product experiences for threads_connect that feel calm, connected, and purposeful. Follow the shared design tokens and standards in the root `AGENTS.md`.

## Workflow

1. Identify the user's goal, key information, and primary action before arranging a screen.
2. Map hierarchy and responsive behavior from narrow to wide layouts.
3. Reuse shared tokens and components in `packages/ui`; introduce a new token only when it has a consistent design role.
4. Specify loading, empty, error, focus, hover, and reduced-motion behavior for interactive surfaces.
5. Check contrast, keyboard access, touch target size, text wrapping, and dark mode.

## Quality checks

- The next action and page purpose are easy to identify.
- Layout adapts without horizontal overflow at mobile widths.
- Semantic structure, visible focus, and sufficient contrast are present.
- Motion is restrained, optional under reduced-motion preferences, and clarifies change.
- Visual choices feel specific to the product rather than copied from a generic dashboard.
